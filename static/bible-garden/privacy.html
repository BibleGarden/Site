Privacy Policy

Last updated: October 4, 2026

Overview

Bible Garden is a free, open-source application for reading and listening to the Bible. We respect your privacy: the app requires no account or personal details. The app sends no analytics; the bible.garden website counts visits anonymously, as described in “The bible.garden Website” below.

Data the App Does Not Collect

  • No accounts or registration required
  • No personal information (name, email, phone)
  • No location data
  • No analytics or tracking SDKs
  • No advertising
  • No cookies

Server Request Data

For every /api request we store the time, path, HTTP method, status and response time. The IP address itself is not stored: we record a pseudonym instead, which cannot be turned back into the address without our secret key. The user agent is stored for all endpoints except the private AI endpoints. The IP address is needed only while a request is processed, to protect against abuse.

Request records are deleted from the live database after 14 days; backups may keep them longer. Only daily counts are kept permanently, including the number of distinct pseudonyms.

Server logs contain no IP address, user agent, referrer or query parameters. An IP address can appear only in the web server’s critical-error log.

Third-Party Services

Bible Garden does not integrate any third-party analytics, advertising, or tracking services. The app communicates only with our own server (api.bible.garden) to retrieve Bible content and audio files.

The bible.garden Website

The bible.garden website (not the app) counts visits with Umami, open-source analytics running on our own server, stats.bible.garden. Umami sets no cookies and stores no IP addresses: the address is used only during the visit to derive an anonymous visitor ID that changes every month. The country comes from Cloudflare; region and city are not stored. What is stored: the page address and title, the site you came from (addresses without query parameters), browser, operating system, device type, screen size, language, country, time of visit and clicks on the App Store link. The statistics stay on our own servers and are not used for advertising or profiling. Records older than 13 months are deleted; backups usually keep them for up to 7 more days. Like the rest of the site, stats.bible.garden runs through Cloudflare, which receives no stored statistics from us.

Open Source

The Bible Garden app and server code is open source under the GPL-3.0 license. You can review it on GitHub to verify these privacy practices yourself.

If we change this policy, we will update the date on this page.
