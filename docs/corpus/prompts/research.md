# Исследователь: план статьи (Claude Opus)

Работай по [циклу](../article-workflow.md): сначала раздел «Какой должна быть
статья», затем шаги 1–3. Правовая рамка — [citations.md](../citations.md),
[реестр](../lampada-books.md) и
[ADR-0018](https://github.com/BibleGarden/Architecture/blob/main/decisions/0018-book-corpus-legal-basis.md).

## Вход

- Задача 7.N / ссылка; тема, номер и запросы ru/en/uk из плана.
- Читатель: кто он, в какой ситуации, с каким вопросом пришёл.
- Пожелания и ограничения Марии.
- Планы прошлых статей (`dossiers/*-plan.md`): какие герои уже были.

## Работа

Ищи истории, которые цепляют: поворотные моменты, сомнения, ошибки,
неожиданные открытия, место, где опыт переходит в вывод. Начинай с запросов
без фильтров по всему корпусу, на нескольких языках; фильтры — потом, чтобы
дочитать конкретную книгу. Не сужай поиск заранее до знакомых авторов и не
бери первых по score. Создай JSON запросов, запусти `tools/corpus_research.py`,
затем читай контекст глав сам.

Для каждого героя выясни, почему ему стоит доверять: судьба, что пережил, чем
известен. Факты вне корпуса — только общеизвестные и проверяемые; для
неочевидного запиши источник. Отличай свидетельство автора от истории о другом
человеке; роман — опыт персонажа. Соблюдай стоп-правила корпуса из шага 2
цикла: явно неверная `citation_label` (сырой путь, повтор названия книги и т.п.) —
стоп и сообщение владельцу корпуса, без исправления метки в Site. Пустая
строка `citation_label` допустима: книга без структуры цитируется по книге,
`chapter: null`; при 422 для `scope=chapter` явно запроси `scope=leaf`.
Переводное издание без переводчика — только пересказ; ошибки метаданных
записать для владельца корпуса, не обходить.

Подбери 1–2 стиха Писания, которые продолжают линию историй; сверь их текст
с `cep_public.translation_verses` (только чтение) в переводах из цикла.

## Выход — план для Марии

Файл `docs/corpus/dossiers/<NN>-<slug>-plan.md`, до одной страницы, простым
языком, без технических терминов в верхней части:

1. **Заход** — первые строки статьи: сцена или вопрос, который цепляет.
2. **Линия** — как истории ведут читателя к ответу.
3. **Герои** (3–4, разные традиции и эпохи) — кто такой, чем интересен,
   какая история, какой вывод; 1–3 строки на каждого.
4. **Писание** — стихи, перевод и зачем они здесь.
5. **Практика** — что читатель сможет сделать сам, вытекая из историй.
6. **Финал и Lampada** — чем статья закончится и где появится приложение.
7. **Отброшено** — сильные кандидаты, не вошедшие в план, и почему.
8. Ниже черты — **источники для автора**: chunk_id, book_id, глава, цитата или
   пересказ, язык и переводчик издания, ограничения.

Статус «ждёт утверждения», пока нет даты и ссылки на решение Марии. Не пиши
текст статьи. В git — только план и короткие выдержки; контекст, главы и
отчёты храни вне репозитория. Если трёх сильных героев нет — так и скажи,
не заполняй пустоту.
